# stargazers-log

A log of the repositories I've starred.

## Run locally

Because the page loads repository data from `events.json`, open it through a local web server rather than directly as a `file://` URL. From this project folder, run:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000> in your browser. Press `Ctrl+C` in the terminal to stop the server.
